# Starter Documentation

A guide to installing and customizing **valaxy-theme-starter**. These pages belong to the theme and should evolve alongside its configuration and releases.

- [Install the theme](./guide/getting-started.md)
- [Configure the theme](./guide/configuration.md)
- [Customize its appearance](./guide/customization.md)
- <a href="../">Explore the live demo</a>

For framework installation, Markdown features and deployment fundamentals, use the [Valaxy documentation](https://valaxy.site). Theme authors should start with [Writing a theme](https://valaxy.site/themes/write).

This documentation uses **valaxy-theme-press**. The demo uses **valaxy-theme-starter**; it is the place to inspect the theme's actual layout and interactions.
